# Documentation
- Class name: WanVideoLoopArgs
- Category: WanVideoWrapper
- Output node: False
- Repo Ref: https://github.com/kijai/ComfyUI-WanVideoWrapper

Looping through latent shift as shown in https://github.com/YisuiTT/Mobius/

# Input types
## Required
- shift_skip
    - Skip step of latent shift
    - Comfy dtype: INT
    - Python dtype: int
- start_percent
    - Start percent of the looping effect
    - Comfy dtype: FLOAT
    - Python dtype: float
- end_percent
    - End percent of the looping effect
    - Comfy dtype: FLOAT
    - Python dtype: float

# Output types
- loop_args
    - The loop_args output is produced by this node.
    - Comfy dtype: LOOPARGS
    - Python dtype: object
