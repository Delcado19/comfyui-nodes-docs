# Documentation
- Class name: LTXVApplySTG
- Category: lightricks/LTXV
- Output node: False
- Repo Ref: https://github.com/Mattabyte/ComfyUI-LTXVideo-Registry_Mattabyte

Defines the blocks to apply the STG to.

# Input types
## Required
- model
    - The model to apply the STG to.
    - Comfy dtype: MODEL
    - Python dtype: torch.nn.Module
- block_indices
    - Comma-separated indices of the blocks to apply the STG to.
    - Comfy dtype: STRING
    - Python dtype: str

# Output types
- model
    - The model output is produced by this node.
    - Comfy dtype: MODEL
    - Python dtype: torch.nn.Module
