# Documentation
- Class name: NormalizeImages
- Category: image/color
- Output node: False
- Repo Ref: https://github.com/comfyanonymous/ComfyUI

Normalize images using mean and standard deviation.

# Input types
## Required
- images
    - Image to process.
    - Comfy dtype: IMAGE
    - Python dtype: torch.Tensor
- mean
    - Mean value for normalization.
    - Comfy dtype: FLOAT
    - Python dtype: float
- std
    - Standard deviation for normalization.
    - Comfy dtype: FLOAT
    - Python dtype: float

# Output types
- images
    - Processed images
    - Comfy dtype: IMAGE
    - Python dtype: torch.Tensor
