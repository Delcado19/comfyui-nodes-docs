# Documentation
- Class name: WanVideoUltraVicoSettings
- Category: WanVideoWrapper
- Output node: False
- Repo Ref: https://github.com/kijai/ComfyUI-WanVideoWrapper

Set UltraVico parameters, attention mode still needs to be set to sageattn_ultravico, https://github.com/thu-ml/DiT-Extrapolation

- model

    - Comfy dtype: WANVIDEOMODEL

- alpha
    - Alpha value for the decay, higher values mean slower decay
    - Comfy dtype: FLOAT
    - Python dtype: float
