# Documentation
- Class name: iToolsPromptRecord
- Category: iTools
- Output node: True
- Repo Ref: https://github.com/MohammadAboulEla/ComfyUI-iTools

Tracks your prompts during node execution or when using ▶ button.
Provides quick access to previously used prompts. Includes a history system that saves your favorite prompts.
