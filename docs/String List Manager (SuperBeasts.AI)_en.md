# Documentation
- Class name: String List Manager (SuperBeasts.AI)
- Category: SuperBeastsAI/Utils
- Output node: False
- Repo Ref: https://github.com/SuperBeastsAI/ComfyUI-SuperBeasts

Re-order or time-expand a list of strings (e.g. prompts or captions) so each item can repeat for N frames. Outputs the adjusted list as a single newline-separated string.
