# Documentation
- Class name: WanVideoBlockList
- Category: WanVideoWrapper
- Output node: False
- Repo Ref: https://github.com/kijai/ComfyUI-WanVideoWrapper

Comma separated list of blocks to apply block swap to, can also use ranges like '0-5' or '0,2,3-5' etc., can be connected to the dense_blocks input of 'WanVideoSetRadialAttention' node

# Input types
## Required
- blocks
    - The blocks input is used by this node during execution.
    - Comfy dtype: STRING
    - Python dtype: str

# Output types
- block_list
    - The block_list output is produced by this node.
    - Comfy dtype: INT
    - Python dtype: int

# Usage tips
- Infra type: unknown
