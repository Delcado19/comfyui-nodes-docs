# Documentation
- Class name: SigmasEditor
- Category: 🎈LAOGOU/Sampling Utils
- Output node: False
- Repo Ref: https://github.com/LAOGOU-666/ComfyUI-LG_SamplingUtils

Interactively adjust sigmas curve by dragging control points

# Input types
## Required
- sigmas
    - Input sigmas schedule to edit
    - Comfy dtype: SIGMAS
    - Python dtype: object
- sigmas_adjustments
    - JSON array of adjusted sigma values for each step
    - Comfy dtype: STRING
    - Python dtype: str
## Hidden
- unique_id
    - The unique_id input is used by this node during execution.
    - Comfy dtype: UNIQUE_ID
    - Python dtype: object

# Output types
- adjusted_sigmas
    - The adjusted_sigmas output is produced by this node.
    - Comfy dtype: SIGMAS
    - Python dtype: object
