# Documentation
- Class name: Make Image Saver Pipe
- Category: ImageSaver/Pipe
- Output node: False
- Repo Ref: https://github.com/Comfy-Org/ComfyUI

Bundles metadata and Image Saver settings into a single Pipe connection.

# Input types
## Required
- simple_saver_config
    - Required standalone Saver Configuration.
    - Comfy dtype: SIMPLE_SAVER_CONFIG
    - Python dtype: object
- metadata_config
    - Required standalone Metadata Configuration.
    - Comfy dtype: METADATA_CONFIG
    - Python dtype: object

# Output types
- pipe
    - The pipe output is produced by this node.
    - Comfy dtype: IMAGESAVER_PIPE
    - Python dtype: object
