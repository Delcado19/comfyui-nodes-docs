# Documentation
- Class name: PixaromaGetNode
- Category: 👑 Pixaroma/🔀 Logic & Flow
- Output node: False
- Repo Ref: https://gitlab.com/pixaroma/ComfyUI-Pixaroma

Read a value that a Set Pixaroma node stored under a name, with no cable. Pick the name from the dropdown and the output carries that Set's value, matching its type. Like Set Pixaroma it exists only in the editor and resolves straight to the original source at run time, so there is no extra cost. Add as many Get nodes as you like for the same name to fan one value out.

# Input types
No inputs are defined in the live ComfyUI metadata.

# Output types
- *
    - The value of the chosen Set Pixaroma node, matching its type.
    - Comfy dtype: *
    - Python dtype: object
