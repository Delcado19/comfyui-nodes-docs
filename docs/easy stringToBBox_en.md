# Documentation
- Class name: easy stringToBBox
- Category: EasyUse/Sam3
- Output node: False

Convert x1,y1,x2,y2 format string to BBOX type

# Input types
## Required
- bbox_string
    - Bounding box coordinates in format: x1,y1,x2,y2 (one per line for multiple boxes)
    - Comfy dtype: STRING
    - Python dtype: str

# Output types
- bbox
    - Parsed bounding box in BBOX format
    - Comfy dtype: BBOX
    - Python dtype: object
