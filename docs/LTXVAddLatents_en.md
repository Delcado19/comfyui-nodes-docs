# Documentation
- Class name: LTXVAddLatents
- Category: latent/video
- Output node: False
- Repo Ref: https://github.com/Lightricks/ComfyUI-LTXVideo

Concatenates two video latents along the frames dimension. latents1 and latents2 must have the same dimensions except for the frames dimension.

# Input types
## Required
- latents1
    - The latents1 input is used by this node during execution.
    - Comfy dtype: LATENT
    - Python dtype: dict
- latents2
    - The latents2 input is used by this node during execution.
    - Comfy dtype: LATENT
    - Python dtype: dict

# Output types
- LATENT
    - The LATENT output is produced by this node.
    - Comfy dtype: LATENT
    - Python dtype: dict

# Usage tips
- Infra type: unknown
