# Documentation
- Class name: AudioConcat
- Category: audio
- Output node: False
- Repo Ref: https://github.com/niknah/audio-general-ComfyUI

Concatenates the audio1 to audio2 in the specified direction.

# Input types
## Required
- audio1
    - The audio1 input is used by this node during execution.
    - Comfy dtype: AUDIO
    - Python dtype: object
- audio2
    - The audio2 input is used by this node during execution.
    - Comfy dtype: AUDIO
    - Python dtype: object
- direction
    - Whether to append audio2 after or before audio1.
    - Comfy dtype: COMBO
    - Python dtype: object

# Output types
- AUDIO
    - The AUDIO output is produced by this node.
    - Comfy dtype: AUDIO
    - Python dtype: object
