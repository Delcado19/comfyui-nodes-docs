# Documentation
- Class name: WanVideoFreeInitArgs
- Category: WanVideoWrapper
- Output node: False
- Repo Ref: https://github.com/kijai/ComfyUI-WanVideoWrapper

https://github.com/TianxingWu/FreeInit; FreeInit, a concise yet effective method to improve temporal consistency of videos generated by diffusion models

# Input types
## Required
- freeinit_num_iters
    - Number of FreeInit iterations
    - Comfy dtype: INT
    - Python dtype: int
- freeinit_method
    - Frequency filter type
    - Comfy dtype: COMBO[STRING]
    - Python dtype: str
- freeinit_n
    - Butterworth filter order (only for butterworth)
    - Comfy dtype: INT
    - Python dtype: int
- freeinit_d_s
    - Spatial filter cutoff
    - Comfy dtype: FLOAT
    - Python dtype: float
- freeinit_d_t
    - Temporal filter cutoff
    - Comfy dtype: FLOAT
    - Python dtype: float

# Output types
- freeinit_args
    - The freeinit_args output is produced by this node.
    - Comfy dtype: FREEINITARGS
    - Python dtype: object
