# Documentation
- Class name: TransformSplat
- Category: 3d/splat
- Output node: False
- Repo Ref: https://github.com/comfyanonymous/ComfyUI

Translate, rotate, and scale a gaussian splat. Non-uniform scale also reshapes every individual splat, slower process.
