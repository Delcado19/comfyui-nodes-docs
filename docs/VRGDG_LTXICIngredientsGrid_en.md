# Documentation
- Class name: VRGDG_LTXICIngredientsGrid
- Category: VRGDG/LTX
- Output node: False
- Repo Ref: https://github.com/vrgamegirl19/comfyui-vrgamedevgirl

Builds an LTX IC-LoRA Ingredients-style reference sheet from dynamic image inputs.
