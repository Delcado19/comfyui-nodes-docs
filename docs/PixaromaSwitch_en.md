# Documentation
- Class name: PixaromaSwitch
- Category: 👑 Pixaroma/🔀 Logic & Flow
- Output node: False
- Repo Ref: https://gitlab.com/pixaroma/ComfyUI-Pixaroma

Switch Pixaroma - pass-through switch that lets you pick one of many wired-in inputs to flow through the output. Wire any number of upstream nodes (up to 32) into the rows, then click a row's toggle to make it active. The active row's wire flows out unchanged - works for any wire type (MODEL, CLIP, IMAGE, STRING, AUDIO, etc).

The node grows automatically as you connect wires: there is always one empty trailing row at the bottom waiting for the next connection. Disconnect a wire to remove its row. Each row has a label you can click to rename, so you remember which input is which.
