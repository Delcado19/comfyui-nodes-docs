# Input types
## Required
- image
    - The image input is used by this node during execution.
    - Comfy dtype: IMAGE

- device
    - The device input is used by this node during execution.
    - Comfy dtype: COMBO[STRING]
    - Python dtype: str

# Output types

    - The IMAGE output is produced by this node.
    - Comfy dtype: IMAGE
    - Python dtype: torch.Tensor
