# Documentation
- Class name: AudioAdjustVolume
- Category: audio
- Output node: False
- Repo Ref: https://github.com/comfyanonymous/ComfyUI

Adjust the volume of the audio by a specified amount in decibels (dB).

# Input types
## Required
- audio
    - The audio input is used by this node during execution.
    - Comfy dtype: AUDIO
    - Python dtype: object
- volume
    - Volume adjustment in decibels (dB). 0 = no change, +6 = double, -6 = half, etc
    - Comfy dtype: INT
    - Python dtype: int

# Output types
- AUDIO
    - The AUDIO output is produced by this node.
    - Comfy dtype: AUDIO
    - Python dtype: object
