# Documentation
- Class name: Image Get Color Swatches
- Category: RES4LYF/images
- Output node: False
- Repo Ref: https://github.com/ClownsharkBatwing/RES4LYF

Get color swatches, in the order they appear, from top to bottom, in an input image. For use with color masks.
