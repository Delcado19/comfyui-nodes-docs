# Documentation
- Class name: EmptyAudio

Empty Audio is a ComfyUI node registered by `comfy_extras.nodes_audio`. The live metadata did not provide a longer description.

# Input types
## Required
- duration
    - Duration of the empty audio clip in seconds
    - Comfy dtype: FLOAT
    - Python dtype: float
- sample_rate
    - Sample rate of the empty audio clip.
    - Comfy dtype: INT
    - Python dtype: int
- channels
    - Number of audio channels (1 for mono, 2 for stereo).
    - Comfy dtype: INT
    - Python dtype: int

# Output types
- AUDIO
    - The AUDIO output is produced by this node.
    - Comfy dtype: AUDIO
    - Python dtype: object
