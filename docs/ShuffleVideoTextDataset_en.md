# Documentation
- Class name: ShuffleVideoTextDataset
- Category: dataset/video
- Output node: False
- Repo Ref: https://github.com/comfyanonymous/ComfyUI

Randomly shuffle the order of pairs of video-text in a list.

# Input types
## Required
- videos
    - List of videos to shuffle.
    - Comfy dtype: VIDEO
    - Python dtype: object
- texts
    - List of texts to shuffle.
    - Comfy dtype: STRING
    - Python dtype: str
- seed
    - Random seed.
    - Comfy dtype: INT
    - Python dtype: int

# Output types
- videos
    - Shuffled videos
    - Comfy dtype: VIDEO
    - Python dtype: object
- texts
    - Shuffled texts
    - Comfy dtype: STRING
    - Python dtype: str
