# Documentation
- Class name: LoadImageDataSetFromFolder
- Category: image
- Output node: False
- Repo Ref: https://github.com/comfyanonymous/ComfyUI

Load a dataset of images from a specified folder and return a list of images. Supported formats: PNG, JPG, JPEG, WEBP.

# Input types
## Required
- folder
    - The folder to load images from.
    - Comfy dtype: COMBO
    - Python dtype: object

# Output types
- images
    - List of loaded images
    - Comfy dtype: IMAGE
    - Python dtype: torch.Tensor
