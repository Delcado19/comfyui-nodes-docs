# Documentation
- Class name: Lora Info (LoraManager)
- Category: Lora Manager/utils
- Output node: False
- Repo Ref: https://github.com/willmiao/ComfyUI-Lora-Manager

Displays information (filename, notes) about the currently selected LoRA. Connect any output from a LoRA Loader or Stacker to the lora_source input, then select a LoRA in the source widget — the info updates automatically. Does not affect workflow execution.
