# Documentation
- Class name: Masks From Color Swatches
- Category: RES4LYF/images
- Output node: False
- Repo Ref: https://github.com/ClownsharkBatwing/RES4LYF

Create masks from a multicolor image using color swatches to identify regions. Returns them as a list.

    - Comfy dtype: COLOR_SWATCHES
