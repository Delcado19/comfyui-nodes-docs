# Documentation
- Class name: VideoRandomTemporalCrop
- Category: video/transform
- Output node: False
- Repo Ref: https://github.com/comfyanonymous/ComfyUI

Randomly crop a continuous range of frames from a video.

# Input types
## Required
- video
    - Input video.
    - Comfy dtype: VIDEO
    - Python dtype: object
- length
    - Number of frames to keep.
    - Comfy dtype: INT
    - Python dtype: int
- seed
    - Random seed.
    - Comfy dtype: INT
    - Python dtype: int

# Output types
- video
    - Cropped video (lazy).
    - Comfy dtype: VIDEO
    - Python dtype: object
