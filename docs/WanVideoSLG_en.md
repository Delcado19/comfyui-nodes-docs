# Documentation
- Class name: WanVideoSLG
- Category: WanVideoWrapper
- Output node: False
- Repo Ref: https://github.com/kijai/ComfyUI-WanVideoWrapper

Skips uncond on the selected blocks

# Input types
## Required
- blocks
    - Blocks to skip uncond on, separated by comma, index starts from 0
    - Comfy dtype: STRING
    - Python dtype: str
- start_percent
    - Start percent of the control signal
    - Comfy dtype: FLOAT
    - Python dtype: float
- end_percent
    - End percent of the control signal
    - Comfy dtype: FLOAT
    - Python dtype: float

# Output types
- slg_args
    - The slg_args output is produced by this node.
    - Comfy dtype: SLGARGS
    - Python dtype: object
